## How konet works
- a user creates an account
- modifies the pre existing color pallette for profie color
- user gets a geneated user code to share with friends
- user codes are used to chat and share bio
- folks add up codes to begin chat
- prebuilt functions check if the user generic code exist
- user can pin chats from a list of chats
- user can search for chats through the search bar
